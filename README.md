# java-lotto-precourse

## 기능 목록 작성
- [ ] 입력 처리
  - [ ] 로또 구입 금액을 입력 받는다
  - [ ] 당첨 번호를 입력받는다
  - [ ] 보너스 번호를 입력받는다
  
- [ ] 로또 관리
  - [ ] 로또 구입 금액을 입력하면 구입 금액에 해당하는 만큼 로또를 발행한다

- [ ] 로또 발행
  - [ ] 1 ~ 45 사이의 로또를 발행한다
  - [ ] 1개의 로또는 중복되지 않은 수를 가진다
  - [ ]  로또 번호는 오름차순으로 정렬한다

- [ ] 당첨
  - [ ] 당첨은 1등부터 5등까지 존재한다
  
- [ ] 결과
  - [ ] 당첨 내역을 출력한다
  - [ ] 수익률을 계산한다
---
- [ ] 예외 처리
  - [ ] 로또 구입 금액은 null이거나 공백일 수 없다 
  - [ ] 로또 구입 금액은 1,000원 단위여야 한다
  - [ ] 로또 구입 금액은 정수여야 한다
  - [ ] 로또 구입 금액이 0보다 커야 한다.
  - [ ] 로또 구입 금액을 정수로 바꿨을 때 오버플로우가 발생해서는 안된다
  - [ ] 당첨 번호는 null이거나 공백일 수 없다
  - [ ] 당첨 번호는 정수여야 한다
  - [ ] 당첨 번호는 1 ~ 45 사이여야 한다
  - [ ] 당첨 번호는 6개여야 한다
  - [ ] 당첨 번호는 중복되지 않아야 한다
  - [ ] 보너스 번호는 null이거나 공백일 수 없다
  - [ ] 보너스 번호는 정수여야 한다
  - [ ] 보너스 번호는 1 ~ 45 사이여야 한다
  - [ ] 보너스 번호는 당첨 번호와 중복되지 않아야 한다
